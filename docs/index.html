Облигационер

ИИ-аналитик облигаций российского рынка. Берёт живые данные Мосбиржи и ФНС, читает свежую отчётность эмитентов, проверяет слухи с форумов и отвечает как кредитный аналитик: вернут ли деньги и достаточно ли за это платят.

● Hermes Agent ● Claude Code ● Claude Agent SDK ● Codex CLI ◐ claude.ai
!

Не является финансовой или инвестиционной рекомендацией. Агент выдаёт аналитику и образовательную информацию, а не индивидуальную инвестиционную рекомендацию. Решения о покупке и продаже ценных бумаг вы принимаете сами и сами за них отвечаете. Языковая модель может ошибаться и неверно понять данные: ключевые цифры проверяйте по первоисточникам. Агент не совершает сделок и не запрашивает доступ к брокерскому счёту.

Как он думает

Десять шагов разбора одной облигации

Порядок зашит в навык. Агент не пропускает шаги и к каждой цифре указывает источник и дату.

  1. Рынокключевая ставка, кривая ОФЗ, инфляция
  2. Карточкакупоны, оферты, спред, ликвидность
  3. ЭмитентРСБУ, МСФО группы, отраслевые метрики
  4. Событиясущественные факты, рейтинги, суды
  5. Форумыгипотезы и их проверка
  6. Свежий отчётчитает PDF, сам пересчитывает метрики
  7. Структурасубординация, поручители, ковенанты
  8. Сравнениедругие выпуски и аналоги по рейтингу
  9. Сценарииставка, спред, дефолт, НДФЛ
  10. Выводскоринг, риски, для кого подходит

Пример формата. Утверждения условные.

  1. 01Собирает свежие обсуждения за 1–3 месяца и отмечает, кто пишет: аноним, аналитик, представитель эмитента, организатор выпуска.
  2. 02Отбрасывает эмоции и вытаскивает конкретные утверждения, которые можно проверить.
  3. 03Сверяет каждое с первоисточником: арбитраж, Федресурс, налоговая, раскрытие эмитента, отчётность, история торгов.
  4. 04Сравнивает настроение на форуме с ценой и спредом. Паника при стабильной цене обычно шум. Тишина при расширении спреда настораживает.
  5. 05В вывод как факт идёт только подтверждённое. Остальное попадает в отдельный блок с пометкой.

    Совместимость
    
Работает в популярных агентных средах

    
Навык сделан по открытому стандарту Agent Skills: одна папка с файлом SKILL.md, справочниками и скриптами. Скрипты написаны на Python без сторонних зависимостей (для PDF нужен pypdf).

  

  

  

    
СредаКак подключитьПоддержка

    
      
Hermes Agent
Linux, macOS, WSL2		отдельный профиль bonds с характером из SOUL.md или навык в основном профилеполная

      
Claude Code
терминал, десктоп, IDE		навык ru-bonds и субагент bonds, установщик для Windows и Unixполная

      
Claude Agent SDKпапка навыка в .claude/skills/ вашего проектаполная

    Установка
    
Одна команда для каждой среды

  

  

    
Hermes Agent
./install.sh            # профиль bonds → bonds chat

    
Claude Code · macOS, Linux
./install.sh claude

    
Claude Code · Windows
powershell -ExecutionPolicy Bypass -File install.ps1 claude

    
Codex CLI
./install.sh codex
