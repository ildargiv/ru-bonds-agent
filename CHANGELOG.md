# Changelog

## v1.0.0

Первый стабильный релиз ru-bonds-agent: ИИ-агент для анализа облигаций РФ.

- навык `skills/finance/ru-bonds` (`SKILL.md`, версия 1.0.0) со справочниками и скриптами;
- субагенты для Claude Code в `agents/claude-code/`;
- установщики `install.sh` и `install.ps1` для Hermes Agent, OpenClaw, Claude Code и Codex CLI;
- база знаний в формате Obsidian-вики, общая для всех агентов семейства;
- `DISCLAIMER.md`: не инвестиционная рекомендация.

Подробности и установка: [README](https://github.com/ildargiv/ru-bonds-agent#readme).
