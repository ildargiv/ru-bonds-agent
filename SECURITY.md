# Безопасность

Поддерживается последняя версия (линейка v1.x).

Нашли уязвимость (например, утечку ключей или данных портфеля через скрипты агента)?
Не публикуйте подробности в открытом issue. Используйте приватное сообщение:
вкладка **Security → Report a vulnerability** в [репозитории](https://github.com/ildargiv/ru-bonds-agent/security/advisories/new).
Если вкладка недоступна, откройте issue без технических подробностей, и с вами свяжутся.

Не прикладывайте к сообщениям и issue ключи, токены, отчёты брокера и данные портфеля.
