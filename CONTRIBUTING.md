# Как помочь проекту

Проект — навык для ИИ-агентов (ИИ-агент для анализа облигаций РФ). Принимаются исправления ошибок, новые источники данных,
уточнения методологии и перевод документации.

1. Откройте issue с описанием проблемы или идеи (шаблоны подскажут, что указать).
2. Для правки сделайте форк и pull request в `main`. Небольшой PR разбирать проще.
3. Перед PR локально выполните то же, что и CI:
   ```bash
   python -m compileall -q skills
   bash -n install.sh
   python .github/scripts/check_skills.py
   ```
4. Меняете поведение навыка — поднимите `version` в его `SKILL.md` и добавьте запись в `CHANGELOG.md`.
5. Не добавляйте в репозиторий личные данные: портфель, ключи, отчёты брокера.

Выпуск версии: запись в `CHANGELOG.md` под заголовком `## vX.Y.Z`, затем тег `vX.Y.Z`;
GitHub Release создаётся автоматически (`.github/workflows/release.yml`).

Проект не даёт инвестиционных рекомендаций, см. [DISCLAIMER.md](DISCLAIMER.md).
