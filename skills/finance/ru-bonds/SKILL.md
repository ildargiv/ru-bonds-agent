# Облигации РФ: полный цикл анализа

## Когда использовать
- Пользователь называет облигацию (тикер, ISIN `RU000A...`, `SU26xxx`, название эмитента) и спрашивает «стоит ли», «что с ней», «почему упала», «какая доходность».
- Нужно подобрать облигации под цель: доходность, срок, риск, ежемесячный купон, флоатеры под высокую ставку, длинные ОФЗ под снижение ставки, ВДО.
- Нужно прочитать свежий отчёт эмитента (МСФО/РСБУ, отчёт эмитента, пресс-релиз, существенный факт) и понять, как он влияет на кредитное качество.
- Вопросы про ключевую ставку, кривую ОФЗ, спреды, стратегию дюрации, налоги на купоны, оферты, амортизацию, дефолты и реструктуризации.

## Инструменты (папка `scripts/`, Python 3.9+, только stdlib; для PDF — `pypdf`)
| Скрипт | Что делает |
|---|---|
| `moex_bond.py <ISIN/SECID/название> [--json]` | Карточка выпуска: эмитент+ИНН, тип купона/база флоатера, листинг, квал/неквал, цена, bid/ask, оборот, НКД, YTM/дюрация/G- и Z-спред от биржи, КБД на сроке дюрации, собственный пересчёт YTM/дюрации/выпуклости и total return при сдвиге ставок ±300 б.п., график купонов, амортизаций, оферт, ссылки на источники |
| `screener.py [фильтры]` | Скрининг всех бумаг по режимам TQCB/TQOB/TQIR/TQOD: доходность, дюрация, оборот, уровень листинга, тип купона, валюта, название; сортировка, CSV |
| `gir_bo.py <ИНН/название> [--json]` | РСБУ из ГИР БО ФНС за все доступные годы + ICR, ЧД/EBIT, маржи, ликвидность, ставка по долгу, доля краткосрочного долга |
| `report_extract.py <URL/PDF> [--grep regex] [--dump file]` | Текст из PDF-отчёта + быстрый поиск ключевых строк (выручка, EBITDA, долг, проценты, ковенанты, going concern, мнение аудитора, поручительства, события после отчётной даты) |
| `macro.py` | Кривая КБД (G-curve) и её форма, индексы RGBI/RUCBTR и др. |
| `bond_math.py` | YTM, дюрация, выпуклость, PV01, сценарии, оценка доходности после НДФЛ (импорт или CLI) |

Запуск: скрипты лежат в папке `scripts/` рядом с этим файлом. Определи папку навыка (где лежит этот SKILL.md) и вызывай `python <папка_навыка>/scripts/moex_bond.py RU000A10DK98`. Типовые места:

- Codex CLI и другие среды со стандартом Agent Skills: каталог навыков этой среды.
Если в Windows `python` не найден — пробуй `python3` или `py`.

Справочники (читай нужный файл по необходимости, не все сразу; в Hermes — `skill_view(ru-bonds, <путь>)`):

## Порядок работы

### A. Разбор конкретного выпуска (глубокий)
1. **Рынок и фон**: `macro.py` → форма кривой, уровень КБД. Ключевую ставку, дату ближайшего заседания ЦБ, консенсус (опрос аналитиков ЦБ), инфляцию, RUONIA — проверь на cbr.ru (веб-поиск/браузер). Никогда не бери ставку из памяти — только свежие данные с датой.
2. **Карточка**: `moex_bond.py <id>` → зафиксируй: тип купона, к чему считается YTM (погашение/оферта/call), дюрацию, G-спред, ликвидность (оборот, bid/ask), амортизацию, оферты, квал/неквал, листинг, флаги дефолта. Если купоны неизвестны — честно скажи и посчитай сценарии (флоатер: база + спред под прогноз ставки; фикс до оферты: доходность к оферте).
3. **Эмитент**: ИНН из карточки → `gir_bo.py <ИНН>` (РСБУ) и параллельно найди **МСФО группы** (сайт эмитента → «Инвесторам», e-disclosure.ru по ИНН). Для банков — отчётность на cbr.ru + МСФО; для лизинга, МФО, девелоперов — отраслевые метрики (см. framework).
4. **Свежие события** (последние 3–6 мес.): существенные факты на e-disclosure.ru (оферты, смена купона, просрочки, допэмиссии, поручительства, смена аудитора, реорганизация), рейтинговые действия (АКРА, Эксперт РА, НКР, НРА — с датой и прогнозом), арбитраж kad.arbitr.ru (иски к эмитенту, особенно банков и налоговой), новости Интерфакс/РБК/Cbonds.
5. **Форумы и сообщество** (по `forums-sentiment.md`): собери свежие обсуждения (Smart-Lab, Пульс, Telegram, banki.ru), вытащи проверяемые утверждения и **проверь каждое** первоисточником (суд, ЦБ, e-disclosure, ЕГРЮЛ, отчётность, история торгов). Сопоставь сентимент с ценой и спредом. В вывод — только подтверждённое; остальное — с пометкой «не подтверждено».
6. **Свежий отчёт**: найди последний опубликованный (квартал/полугодие/год) → `report_extract.py <URL>` → затем прочитай ключевые страницы целиком (баланс, ОПУ, ДДС, примечание «Кредиты и займы», «Связанные стороны», «События после отчётной даты», мнение аудитора). Посчитай метрики сам — не верь «скорректированной EBITDA» компании без сверки.
7. **Структура выпуска**: место в структуре долга (суборд/старший, обеспечение, поручители и их качество), ковенанты, put/call, амортизация, график погашений всего долга (стена рефинансирования на 12–18 мес. vs деньги + свободные лимиты).
8. **Относительная стоимость**: сравни с другими выпусками того же эмитента (`screener.py --name`) и с бумагами того же рейтинга/срока (`screener.py --listlevel ... --min-dur-days ... --max-dur-days ...`). Премия за риск адекватна? Почему рынок даёт такую доходность?
9. **Сценарии**: total return на 6–12 мес. при разных траекториях ключевой ставки и спреда; доходность после НДФЛ; что будет при дефолте (оценка recovery).
10. **Вывод** по шаблону `report-template.md`: кредитный скоринг, ключевые риски, триггеры пересмотра, для какого инвестора подходит, позиционирование (доля в портфеле) — без категоричных «покупай всё».

### B. Подбор / скрининг
1. Уточни цель (если не сказана): горизонт, нужна ли регулярная выплата, налоговый режим (ИИС/ЛДВ), квалификация, допустимый риск (только 1–2 уровень листинга / рейтинг ≥ A- / ВДО), объём (важна ликвидность).
2. `screener.py` с фильтрами. Отсекай: структурные (`struct`), предефолтные (YTM > 40–60%, цена < 70 без причины), неликвид (оборот < 1 млн ₽/день для частного инвестора), бумаги с офертой/погашением ближе 1–2 мес., если цель — доходность.
3. По 5–15 кандидатам — короткий разбор по шагам A2–A5: рейтинг, свежие новости, метрики, быстрая проверка форумов на тревожные сигналы. Объясни, почему кандидат отсеян.
4. Предложи 2–3 варианта портфеля (консервативный / сбалансированный / доходный) с диверсификацией: ≤ 5% на ВДО-эмитента, ≤ 10% на корпорат IG, лестница погашений, микс фикс/флоатер/ОФЗ под взгляд на ставку.

### C. «Прочитай свежий отчёт компании X»
1. Найди документ: сайт эмитента (раздел «Инвесторам/Раскрытие»), e-disclosure.ru (вкладка «Отчётность» → МСФО / «Отчёт эмитента»), ГИР БО для РСБУ. Проверь дату и период; убедись, что это последняя версия (а не прошлогодняя).
2. `report_extract.py <URL> --dump /tmp/x.txt`, затем читай текст по разделам (см. `reading-reports.md`).
3. Сравни с предыдущим периодом (LTM, г/г), с ковенантами, с прогнозами менеджмента и рейтинговых агентств.
4. Ответ: что изменилось для держателя облигаций (долг, покрытие процентов, ликвидность, рефинансирование), а не пересказ отчёта.

### D. Макро и ОФЗ
- Кривая КБД + ожидания по ставке → где выгоднее стоять на кривой; длинные фикс ОФЗ = ставка на снижение КС; флоатеры (ОФЗ-ПК на RUONIA) = защита от неснижения; линкеры ОФЗ-ИН = ставка на инфляцию выше ожиданий.
- Аукционы Минфина (minfin.gov.ru) — объёмы, премии, спрос — влияют на длинный конец.

## Правила (обязательные)
- **Только свежие данные с датой и источником.** Ставка ЦБ, рейтинги, цены, отчёты — проверяй в момент ответа. Если данных нет — скажи, чего не хватает, и где взять.
- **Не выдумывай цифры.** Каждая цифра — с источником (скрипт/URL/страница отчёта). Различай РСБУ юрлица и МСФО группы.
- **Форумы — источник гипотез, не фактов.** Слухи всегда проверяй и помечай статус (✅/❌/⚠️/💬). Но не игнорируй их: сообщество часто первым замечает проблемы.
- **Высокая доходность = высокий риск** — всегда объясняй, за что рынок даёт премию.
- Это аналитика, а не индивидуальная инвестиционная рекомендация (ИИР): давай взвешенный вывод, сценарии и риски; решение — за пользователем. Не исполняй сделки.
- Ответ на русском, структурно, сначала вывод (TL;DR), потом аргументы. Суммы — в ₽ с разрядами, доходности — в % годовых, спреды — в б.п.
- При отказе API (MOEX/ГИР БО) — повтори, затем используй веб-источники (smart-lab, dohod, rusbonds, cbonds) и отметь это.
