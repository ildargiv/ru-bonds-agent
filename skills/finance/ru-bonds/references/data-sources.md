# Где брать информацию по облигациям РФ

Приоритет: **первоисточник** (биржа, ЦБ, ФНС, раскрытие эмитента, рейтинговое агентство) > агрегатор > СМИ > форумы/Telegram.
Всегда фиксируй дату данных.

## 1. Рыночные данные
| Источник | URL | Что брать | Примечание |
|---|---|---|---|
| **MOEX ISS API** (бесплатно, без ключа) | `https://iss.moex.com/iss/...` | Котировки, доходности, дюрация, G/Z-спред, купоны, амортизации, оферты, история торгов, КБД, индексы | Используется скриптами. Задержка ~15 мин для бесплатного доступа |
| — карточка | `/iss/securities/{SECID}.json` | Параметры выпуска (база флоатера, листинг, квал) | |
| — рынок | `/iss/engines/stock/markets/bonds/securities/{SECID}.json` | `securities`, `marketdata`, `marketdata_yields` | |
| — купоны/аморт./оферты | `/iss/statistics/engines/stock/markets/bonds/bondization/{SECID}.json` | Полный график платежей | Пагинация по 100 строк |
| — все бумаги режима | `/iss/engines/stock/markets/bonds/boards/{TQCB,TQOB,TQIR,TQOD}/securities.json` | Скрининг | |
| — история | `/iss/history/engines/stock/markets/bonds/securities/{SECID}.json?from=YYYY-MM-DD` | Цены, обороты, доходности по дням | |
| — КБД | `/iss/engines/stock/zcyc.json` | Кривая бескупонной доходности ОФЗ | |
| — поиск | `/iss/securities.json?q={ISIN или текст}` | SECID, эмитент, **ИНН эмитента** | |
| Сайт Мосбиржи | moex.com/ru/issue.aspx?code=SECID | Документы выпуска (эмиссионные док-ты, проспект), расписание | |
| Smart-Lab | smart-lab.ru/q/bonds/ | Удобные таблицы, обсуждения эмитента (сигнал, не факт) | |
| Доход | dohod.ru/analytic/bonds | «Анализ облигаций»: свой кредитный рейтинг Доход, ликвидность, сводка | Полезно для 2-го мнения |

| Cbonds | cbonds.ru | Наиболее полная база, новости, календарь размещений, индексы | Платно; новости — частично бесплатно |
| Финам / Т-Инвестиции / БКС | bonds.finam.ru и др. | Календарь купонов, размещения | |

| Эксперт РА | raexpert.ru |

Смотри: уровень, **прогноз** (позитивный/стабильный/негативный), статус «на пересмотре», **дату** действия, пресс-релиз с обоснованием (там ключевые метрики и допущения агентства). Отзыв рейтинга по инициативе эмитента — тревожный сигнал. Реестр рейтингов — также на cbr.ru.

## 5. Новости и аналитика
- Новостные ленты: Интерфакс (interfax.ru, раздел «Финансы» / «Рынки»), ПРАЙМ, РБК Инвестиции, Коммерсантъ, Ведомости, Cbonds News.
- Аналитика брокеров/банков (обзоры рынка долга, кредитные комментарии): Т-Инвестиции, БКС, Альфа, Газпромбанк, Совкомбанк, Райффайзенбанк, ИК «Доход», Финам — используй как мнение.
- Календари: Cbonds/Финам/Smart-Lab — новые размещения (book building, ориентиры купона), оферты, погашения.
- **Форумы и соцсети** (Smart-Lab, Пульс, Telegram, banki.ru, отзывы сотрудников) — ранние сигналы и слухи. Использовать обязательно, но только как гипотезы: протокол проверки — в `forums-sentiment.md`.

## 6. Нормативка и налоги
- Налог на купоны и доход от погашения: НДФЛ по прогрессивной шкале (13% … выше при больших доходах); льготы по ИИС 3-го типа; ЛДВ (3 года) к купонам не применяется. Проверяй актуальные ставки в НК РФ/на nalog.gov.ru.
- Ограничения для неквалифицированных инвесторов (тестирование для облигаций ниже определённого рейтинга, структурные, иностранные): регулируется ЦБ/базовым стандартом — проверяй актуальную редакцию.
- Требования к раскрытию, дефолты и ПВО (представитель владельцев облигаций): закон «О рынке ценных бумаг», решение о выпуске.

## 7. Чек-лист поиска свежего отчёта
1. `moex_bond.py` → ИНН эмитента.
2. e-disclosure.ru → поиск по ИНН → «Отчётность» → последняя МСФО/«Отчёт эмитента»; «События» за 6 мес.
3. Сайт эмитента → «Инвесторам» → пресс-релиз и презентация (часто раньше PDF).
4. ГИР БО (`gir_bo.py`) → РСБУ за год (с апреля следующего года).
5. Веб-поиск: `"<эмитент>" МСФО 1 полугодие 2026` / `"<эмитент>" отчётность 9 месяцев` / `site:e-disclosure.ru <ИНН>`.
6. Поручитель/оферент — тот же цикл, если долг фактически обслуживает он.
