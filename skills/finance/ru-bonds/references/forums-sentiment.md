# Форумы и соцсети: источник гипотез, а не фактов

Форумы часто **первыми** замечают проблемы эмитента (задержки зарплат, иски, слухи о реструктуризации, странные продажи в стакане, ответы эмитента на вопросы инвесторов). Но там же — ошибки, паника, «пампы» владельцев бумаг и заказные вбросы.
**Правило: ничего с форума не идёт в вывод как факт, пока не подтверждено первоисточником.** Зато каждое значимое утверждение — повод проверить.

## Где смотреть
| Площадка | Как искать | Особенности |
|---|---|---|
| Smart-Lab | веб-поиск `site:smart-lab.ru "<эмитент>" облигации`; страница бумаги `smart-lab.ru/q/bonds/<SECID>/`; форум эмитента через smart-lab.ru/forum/ (по алфавиту); блоги аналитиков по ВДО | Самое активное облигационное сообщество, блоги эмитентов ВДО (ответы менеджмента) |
| Пульс (Т-Инвестиции) | веб-поиск `"<эмитент>" пульс тинькофф` / страница бумаги в Пульсе | Массовый розничный сентимент, много шума |
| Telegram-каналы по облигациям/ВДО | веб-поиск `"<эмитент>" облигации telegram`, t.me/s/<канал> (веб-превью) | Быстро, часто авторы — организаторы/инвесткомпании (конфликт интересов!) |
| Banki.ru форум | `site:banki.ru "<эмитент>"` | Для банков/МФО: жалобы клиентов, задержки выплат |
| Отзывы сотрудников (dreamjob, hh) | `"<эмитент>" отзывы сотрудников зарплата задержка` | Ранний индикатор кассовых разрывов у ВДО |
| YouTube/VC.ru/Дзен | веб-поиск | Встречи с эмитентами, интервью менеджмента |

## Протокол обработки (обязательный)
1. **Собрать** 10–30 свежих сообщений (последние 1–3 месяца) с датами и ссылками. Отметить автора: аноним / известный аналитик / представитель эмитента / организатор выпуска.
2. **Извлечь проверяемые утверждения**, отбросив эмоции: «у компании иск от Сбера на 300 млн», «купон задержали на день», «владелец выводит деньги через займы», «рейтинг отзовут», «новый выпуск размещают, чтобы погасить старый».
3. **Классифицировать** каждое: факт о событии / цифра / слух / мнение / прогноз.
4. **Проверить** через первоисточник:
   | Утверждение про… | Где проверять |
   |---|---|
   | суды, иски, банкротство | kad.arbitr.ru, fedresurs.ru |
   | налоговые долги, блокировки | pb.nalog.ru, ФССП |
   | задержку купона/оферты, решения СД, изменения условий | e-disclosure.ru (существенные факты), moex_bond.py (график выплат) |
   | рейтинг | сайт агентства |
   | финансовые цифры | МСФО/РСБУ (`gir_bo.py`, `report_extract.py`) |
   | собственников, связанные компании | ЕГРЮЛ, checko/rusprofile |
   | продажи в стакане, обвал цены | MOEX history (обороты, цены по дням) |
   | ставку, макро | cbr.ru |
5. **Присвоить статус**: ✅ подтверждено (ссылка) · ❌ опровергнуто (ссылка) · ⚠️ не удалось проверить · 💬 мнение.
6. **Оценить сентимент** (позитив/нейтрально/паника) и **сопоставить с рынком**: паника на форуме + стабильная цена и спред → вероятно шум; тишина на форуме + расширение спреда → кто-то знает больше; паника + подтверждённые факты → серьёзный сигнал.
7. **Использовать в выводе** только подтверждённое как факт; неподтверждённое — в разделе «Сигналы сообщества, требующие внимания» с явной пометкой.

## Фильтр манипуляций
- Автор держит бумагу/организатор выпуска/«агент» эмитента — мнение предвзято.
- Синхронные однотипные посты от новых аккаунтов — вероятный вброс.
- «Срочно продавайте/покупайте» без источников — игнорировать как факт.
- Скриншоты «документов» без ссылки на реестр/раскрытие — не доказательство.
- Ответы представителя эмитента на форуме полезны, но сверяй с официальным раскрытием (обещания ≠ обязательства).

## Формат в ответе
```
### Сигналы с форумов (за <период>, N сообщений, сентимент: <…>)
| Утверждение | Источник (дата) | Проверка | Статус |
|---|---|---|---|
| Иск банка X на 250 млн ₽ | smart-lab, 12.10 | kad.arbitr.ru дело А40-… | ✅ подтверждено |
| «Купон задержат» | Пульс, 15.10 | e-disclosure: фактов нет; купон 21.10 по графику | ⚠️ не подтверждено |
Вывод: <как это меняет оценку риска или почему не меняет>.
```
