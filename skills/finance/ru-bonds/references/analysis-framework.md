# Методология анализа облигаций (уровень профи)

Анализ = **рынок** (сколько платят и почему) + **структура** (что именно купили) + **кредит** (вернут ли) + **относительная стоимость** (не переплачиваем ли) + **сценарии** (что будет, если…).

---
## 1. Рыночный анализ
**Доходность**
- YTM эффективная (MOEX считает с реинвестированием по той же ставке) — к погашению, **к оферте** (put — инвестор может предъявить; call — эмитент может погасить) или к ближайшей дате пересмотра купона. Всегда указывай, к какой дате.
- Текущая доходность = купон / чистая цена — для «купонного потока».
- Доходность после налогов: купон × (1 − НДФЛ); дисконт при погашении тоже облагается. Бумаги с низким купоном и глубоким дисконтом (старые ОФЗ) налогово эффективнее: налог с дисконта платится в конце.
- Флоатер: эффективная доходность ≈ ожидаемая средняя база (КС/RUONIA) за срок + спред. Сравнивай **спред к базе**, а не YTM от биржи (биржа считает по текущему купону).
- Линкер (ОФЗ-ИН): реальная доходность + фактическая инфляция; breakeven-инфляция = YTM номинальной ОФЗ аналогичного срока − реальная доходность линкера.

**Чувствительность**
- Дюрация Маколея (лет) и **модифицированная**: ΔP/P ≈ −D_mod·Δy + ½·C·Δy². Пример: D_mod 5 → рост ставок на 1 п.п. ≈ −5% цены.
- PV01 — изменение стоимости при сдвиге на 1 б.п. Для портфеля суммируй.
- Флоатер на КС: процентная дюрация ≈ до ближайшего пересмотра купона, но **кредитная (спредовая) дюрация** = до погашения.

**Спреды**
- G-спред = YTM − КБД ОФЗ на сроке дюрации (MOEX даёт `GSPREADBP`). Z-спред — к всей кривой.
- Ориентиры (меняются с рынком — калибруй по текущему скринингу!): AAA ≈ +50–150 б.п.; AA ≈ +100–250; A ≈ +200–450; BBB ≈ +400–800; BB и ниже/ВДО ≈ +700…+2000. Спред сильно выше рейтинговой группы = рынок видит проблему, которую нужно найти.
- Динамика спреда за 1–3 мес. (`/iss/history`): расширение без новостей — кто-то знает больше (продажи инсайдеров/фондов).

**Ликвидность**
- Оборот/день, число сделок, bid-ask. Для частного инвестора: оборот < 1 млн ₽ — риск не выйти без потерь. Объём выпуска < 500 млн ₽ — малоликвиден.

**Форма кривой и ставка**
- Инвертированная кривая (короткие > длинных) — рынок ждёт снижения ставки. Покупка длинных фикс-бумаг = ставка на снижение; флоатеры/короткие — защита.
- Ключевые драйверы: решения ЦБ и сигнал, траектория в среднесрочном прогнозе, инфляция и ожидания, бюджет/аукционы Минфина, курс рубля, геополитика.

## 2. Структурный анализ выпуска
- **Тип купона**: фикс известный / фикс до оферты (дальше купон назначит эмитент — риск низкого купона и необходимость предъявить) / флоатер (база, спред, лаг фиксации, cap/floor) / линкер / структурный (выплаты от событий — для неквалов обычно исключать).
- **Оферты**: put — право инвестора продать по 100% (подать заявку в окно предъявления через брокера!); call — право эмитента погасить (ограничивает рост цены выше 100; YTM считать к call, если купон выше рынка).
- **Амортизация**: снижает дюрацию и риск, но и купон начисляется на остаток номинала; реинвестиция.
- **Обеспечение**: поручительство/оферта материнской компании (кто реальный должник?), залог, госгарантия (субфедеральная/федеральная).
- **Субординация**: субордированные и бессрочные выпуски банков (AT1/T2) — могут быть списаны или конвертированы при санации/нарушении нормативов, купон может быть отменён. Это не депозит.
- **Ковенанты**: финансовые (ЧД/EBITDA ≤ X), cross-default, change of control, ограничение выплат — нарушение даёт право досрочного погашения (по решению ОСВО).
- **Валюта**: замещающие (USD/EUR, выплаты в рублях по курсу), юаневые — валютный риск/хедж, особенности расчётов, иностранная инфраструктура (риски блокировок).
- **Квал/неквал**, уровень листинга (1–3), сектор ПИР (TQIR) — повышенный риск, у брокера может требоваться тест.
- Порядок, календарь и место выпуска в **графике погашений всего долга** эмитента.

## 3. Кредитный анализ (вернут ли деньги)

### 3.1 Бизнес-риск
- Отрасль: цикличность, зависимость от ставки (девелопмент, лизинг, ритейл в кредит), от экспорта/санкций/курса, регулирование, господдержка (системообразующие, госкомпании).
- Позиция: доля рынка, масштаб (выручка < 1 млрд ₽ — микроэмитент), диверсификация клиентов/поставщиков, концентрация на 1–2 контрактах.
- Собственники и корпоративное управление: кто бенефициар, поддержка группы, сделки со связанными сторонами, аудитор (Big-4-наследники «Технологии Доверия», Kept, ДРТ, Б1, или «нонейм»?), история раскрытия, отношение к инвесторам.

### 3.2 Финансовые метрики (LTM, динамика 3–5 периодов)
| Метрика | Формула | Комфорт (обычный корпорат) | Тревога |
|---|---|---|---|
| Долговая нагрузка | Чистый долг / EBITDA LTM | < 2.5x | > 4x (для ВДО > 3.5x) |
| Покрытие процентов | EBITDA / процентные расходы (ICR) | > 3x | < 1.5x; < 1x = проедает капитал |
| EBIT / проценты | | > 2x | < 1x |
| Ликвидность | (Деньги + невыбранные **подтверждённые** лимиты) / Краткосрочный долг | > 1.5x | < 1x — «стена рефинансирования» |
| Структура долга | Краткосрочный долг / Весь долг | < 30% | > 50% |
| FCF | Опер. CF − Capex − проценты | > 0 | устойчиво < 0 при росте долга |
| Капитализация | Капитал / Активы | > 30% | < 10%, отрицательный капитал |
| Средняя ставка долга | Проценты / Средний долг | Ниже рынка — рост расходов при рефинансировании! | |
| Оборотный капитал | Дебиторка, запасы — дни оборота | стабильны | резкий рост дебиторки (выручка «на бумаге») |

**Корректировки**: аренда (МСФО 16) — смотреть с ней и без; капитализированные проценты; займы выданные связанным сторонам (часто «утечка» денег из облигационного эмитента); «скорректированная EBITDA» компании vs собственный расчёт; разовые доходы (переоценка, курсовые разницы); деньги на ограниченных счетах (эскроу у девелоперов).

### 3.3 Отраслевые особенности
- **Банки**: Н1.0/Н1.1/Н1.2 и запас над минимумом с надбавками, ROE, стоимость риска (CoR), доля проблемных кредитов (Stage 3), ликвидность (Н2/Н3, LCR для СЗКО), зависимость от фондирования ЦБ/госсредств, концентрация. Субординированные — отдельный риск списания.
- **Лизинг**: качество портфеля (просрочка 90+, изъятия, реализация изъятой техники), структура по отраслям (грузовой транспорт — циклично), Капитал/Активы (> 12–15%), совпадение сроков активов и пассивов, доля облигаций в фондировании.
- **МФО**: регулирование ЦБ (ПДН, макропруденциальные лимиты), просрочка, CoR, норматив достаточности капитала, зависимость от рефинансирования.
- **Девелоперы**: проектное финансирование с эскроу (покрытие эскроу кредита), продажи в м² и ₽, доля ипотеки и льготных программ, корпоративный долг вне ПФ, земельный банк, сроки ввода.
- **Сырьё/экспортёры**: цены, курс, логистика, экспортные пошлины, санкции, НДПИ.
- **Ритейл/потреб**: LFL, маржа, оборачиваемость запасов, аренда.
- **Холдинги/SPV**: эмитент — «пустышка», смотри поручителя и консолидированную группу; маркетплейсы — источник непрозрачной выручки.
- **Муниципалы/субфедералы**: госдолг/собственные доходы, дефицит бюджета, трансферты, рейтинг региона.

### 3.4 Скоринг (0–100, итог в класс риска)
| Блок | Вес | Что оцениваем |
|---|---|---|
| Бизнес и отрасль | 15 | масштаб, позиция, цикличность, господдержка |
| Долговая нагрузка | 20 | ЧД/EBITDA, тренд |
| Покрытие и денежный поток | 20 | ICR, FCF, ставка рефинансирования |
| Ликвидность и рефинансирование | 20 | стена погашений vs деньги/лимиты, доступ к рынку |
| Корпоративное управление и раскрытие | 10 | прозрачность, аудитор, связанные стороны, история |
| Рейтинг и внешние сигналы | 10 | рейтинг/прогноз, суды, налоги, новости, **подтверждённые** сигналы форумов |
| Структура выпуска | 5 | оферты, обеспечение, ковенанты, субординация |

Классы: **80–100** надёжно (уровень A и выше) · **65–79** умеренный риск · **50–64** повышенный (BB–BBB-, малые доли) · **35–49** спекулятивный (ВДО, ≤ 1–2% портфеля) · **< 35** высокий риск дефолта.
Обязательно сопоставь скоринг с доходностью: «плачу ли я достаточно за этот риск?» Ожидаемые потери ≈ PD × (1 − recovery); для ВДО recovery часто 0–30%, у реструктуризаций — растянутые сроки.

### 3.5 Красные флаги (любой → углублённая проверка)
- Технический дефолт (даже «исправленный»), задержка купона, «временные технические проблемы».
- Новый выпуск с купоном сильно выше старых выпусков / рынка — эмитенту не дают денег дешевле.
- Выпуск новых облигаций для погашения старых при отрицательном FCF (пирамида рефинансирования).
- Оферта с низким купоном/предложением «обмена», реструктуризация, ОСВО об изменении условий.
- Иски банков и ФНС, блокировки счетов, заявления о намерении банкротства на Федресурсе.
- Отзыв рейтинга по инициативе эмитента, понижение/негативный прогноз, «на пересмотре».
- Смена аудитора/мнение с оговоркой/отказ/«существенная неопределённость в непрерывности».
- Займы, выданные бенефициару/связанным сторонам; резкий рост дебиторки; выручка от связанных компаний.
- Запоздалое раскрытие, удаление отчётов, смена финдиректора, продажа долей.
- Резкое падение цены/рост спреда без новостей, крупные продажи.
- Зависимость от одной льготной программы/госсубсидии/крупного клиента.

## 4. Относительная стоимость
- Карта «G-спред vs дюрация» по эмитентам одного рейтинга — кто выше линии, тот дёшев (или проблемен).
- Внутри эмитента: выпуски с разной дюрацией — нормальная ли кривая эмитента; аномально дешёвый выпуск — смотри оферту/амортизацию/ликвидность.
- Первичка: ориентир купона vs вторичка эмитента и аналогов (премия за новый выпуск), финальный купон снижен на книге = высокий спрос.
- Фикс vs флоатер vs ОФЗ: что выгоднее при консенсусе ЦБ и при альтернативных сценариях.

## 5. Сценарии и портфель
- Сценарии ставки: базовый (консенсус макроопроса ЦБ), ястребиный (+100–200 б.п. к базовому), голубиный (−100–200 б.п.). Для каждого — total return за 6/12 мес. (`bond_math.scenarios`), учитывая купоны и переоценку.
- Кредитный стресс: расширение спреда на 200–500 б.п. для BBB/ВДО.
- Портфель: лестница погашений; диверсификация по эмитентам/отраслям; лимиты (ОФЗ без лимита, IG ≤ 10%, BB ≤ 5%, ВДО ≤ 1–3% на эмитента, суммарно ВДО ≤ 20–30% только для подготовленного инвестора); резерв ликвидности; совпадение денежного потока с целями.
- Купонный календарь: ежемесячный поток собирается из бумаг с разными датами купонов.

## 6. Типичные ошибки (предупреждай пользователя)
- Сравнивать YTM флоатера с YTM фикса «в лоб».
- Не заметить оферту (call) — доходность к погашению недостижима.
- Пропустить окно предъявления по put-оферте.
- Покупать «выше 100» бумагу с близкой амортизацией/call — гарантированный убыток на цене.
- Считать облигации банка «как депозит» (суборд, АСВ не страхует).
- Игнорировать НДФЛ и комиссию брокера на коротких бумагах.
