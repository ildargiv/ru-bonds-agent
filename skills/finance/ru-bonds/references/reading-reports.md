# Как читать отчётность эмитента глазами облигационера

Цель — не пересказать отчёт, а ответить: **хватит ли денег платить купоны и гасить/рефинансировать долг в ближайшие 12–24 месяца, и стало ли лучше или хуже.**

## 0. Какой документ
| Документ | Где | Когда выходит | Ценность |
|---|---|---|---|
| МСФО группы (год/полугодие, иногда квартал) | сайт эмитента, e-disclosure.ru | год — до конца апреля; полугодие — до конца августа/сентября | Главный документ: консолидированная картина, примечания по долгу |
| Пресс-релиз и презентация | сайт эмитента | одновременно с МСФО или раньше | Скорректированные метрики компании (EBITDA, ЧД) — **сверяй** |
| РСБУ юрлица | ГИР БО, e-disclosure | год, + квартальные у эмитентов | Важно, если эмитент ≠ группа или МСФО нет (ВДО) |
| Отчёт эмитента (полугодовой) | e-disclosure | | Структура группы, риски, корпоративное управление, сделки |
| Существенные факты | e-disclosure «События» | в течение 1–2 дней | Купоны, оферты, просрочки, сделки, решения СД |
| Пресс-релизы рейтинговых агентств | сайт агентства | при действии | Независимая оценка метрик и прогнозов |
| Отчётность банков 101/102/123/135 | cbr.ru | ежемесячно | Для банков — главный оперативный источник |

Проверь: период, дату подписания, аудирован/обзорная проверка (review) / без проверки; это группа или юрлицо; валюта и единицы (тыс./млн).

## 1. Порядок чтения МСФО (≈ 20 минут)
1. **Аудиторское заключение** (в начале): мнение без оговорок? Есть ли «существенная неопределённость в отношении непрерывности деятельности», «ключевые вопросы аудита», оговорки? Кто аудитор?
2. **Отчёт о прибылях и убытках**: выручка (г/г), операционная прибыль, **финансовые расходы** (рост = дорогое рефинансирование), курсовые разницы, обесценения, разовые статьи, чистая прибыль.
   - EBITDA (если не дана) = операционная прибыль + амортизация (из ДДС или примечания) ± разовые статьи.
   - LTM = последний год + текущий период − аналогичный период прошлого года.
3. **Баланс**: денежные средства (и ограниченные!), дебиторка, запасы, займы выданные (кому?), долгосрочные/краткосрочные кредиты и займы, облигации, аренда, капитал (не стал ли отрицательным?).
4. **Отчёт о движении денежных средств**: операционный поток **до и после** изменения оборотного капитала и уплаченных процентов; capex; выданные займы; дивиденды; привлечение/погашение долга. FCF = OCF − capex − проценты (если проценты в финансовой деятельности).
5. **Примечание «Кредиты и займы»**: структура (банки/облигации/связанные стороны), валюта, ставки (фикс/плавающая — чувствительность к КС!), **график погашений**, залоги, **ковенанты и их соблюдение** (нарушение → долг переклассифицирован в краткосрочный).
6. **Связанные стороны**: займы/выручка/закупки с бенефициаром — главный канал «утечки» денег у ВДО.
7. **Условные обязательства**: поручительства за третьих лиц, судебные иски, налоговые претензии.
8. **События после отчётной даты**: новые выпуски, рефинансирования, сделки M&A, дивиденды, дефолты.
9. **Сегменты**: какой бизнес генерирует деньги.

## 2. Расчёт ключевых метрик (собственный)
```
Долг = кредиты и займы (долг.+кратк.) + облигации [+ аренда — указывай отдельно]
Чистый долг = Долг − денежные средства (без ограниченных) − краткосрочные депозиты
EBITDA LTM, ЧД/EBITDA, EBITDA/Проценты, Краткосрочный долг / (Деньги + лимиты)
OCF, capex, FCF, FCF после процентов и дивидендов
```
Сравни с: прошлым периодом, ковенантами, оценкой рейтингового агентства, отраслевыми аналогами.

## 3. Сигналы из отчёта
**Позитив**: рост EBITDA быстрее долга; удлинение долга; снижение доли краткосрочного; положительный FCF; рост денег; снижение средней ставки; новые подтверждённые лимиты; запас по ковенантам.
**Негатив**: проценты > EBITDA (ICR < 1); долг растёт, а выручка нет; краткосрочный долг > денег без лимитов; рост дебиторки/займов связанным; капитал < 0; аудит с оговорками/going concern; переклассификация долга в краткосрочный; обесценения; рост налоговой задолженности.

## 4. Практика с инструментами
```bash
python scripts/report_extract.py "<URL PDF>"                    # обзор ключевых строк со страницами
python scripts/report_extract.py "<URL PDF>" --dump /tmp/r.txt  # полный текст → читай нужные страницы
python scripts/report_extract.py "<URL PDF>" --grep "погашени|ковенант|лимит"
python scripts/gir_bo.py <ИНН>                                  # РСБУ за годы для сверки
```
Если PDF — скан (нет текста): попробуй браузер/vision-инструменты Hermes на нужных страницах или OCR (`ocrmypdf`).
Если отчёт в виде таблиц на сайте или XLSX — читай напрямую.

## 5. Формат вывода по отчёту
1. TL;DR (2–3 строки): лучше/хуже/без изменений для облигационеров и почему.
2. Таблица ключевых метрик: текущий период vs прошлый (LTM), с источником (стр. отчёта).
3. Долг и ликвидность: график погашений 12–18 мес. vs деньги/лимиты/OCF.
4. Риски и сюрпризы из примечаний.
5. Вывод для выпусков эмитента: изменение скоринга, адекватность спреда.
